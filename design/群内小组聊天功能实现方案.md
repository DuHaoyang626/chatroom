# 群内小组聊天功能实现方案

## 📋 需求分析

根据老师要求，需要实现以下功能：

### 🎯 核心功能
1. **群内小组聊天功能**：
   - 群内成员可以邀请部分群成员加入小组
   - 接受邀请后形成小组（类似子群）
   - 小组内聊天，群中未加入小组的成员**不能收到消息**

2. **多小组并发聊天功能**：
   - 允许一个群成员接收**多个小组邀请**
   - **但不允许一个群成员同时加入两个小组**（关键约束）

## 🏗️ 技术架构设计

### 1. 数据库层扩展

#### 新增数据表结构：
- `chat_subgroup` - 群内小组表
- `chat_subgroup_member` - 小组成员表  
- `chat_subgroup_invite` - 小组邀请表
- `chat_subgroup_msg` - 小组消息表

#### 关键约束设计：
```sql
-- 确保一个用户在同一个父群中只能同时参与一个小组
UNIQUE KEY uk_user_parent_group (user_id, parent_group_id) 
  WHERE status = 1 IN chat_subgroup_member
```

### 2. 业务逻辑层

#### 核心服务接口：
- `ChatSubgroupService` - 小组业务服务
- `ChatSubgroupInviteService` - 邀请管理服务
- `ChatSubgroupMessageService` - 小组消息服务

#### 关键业务规则：
1. **互斥性检查**：加入新小组前检查是否已在其他小组
2. **权限控制**：只有小组成员才能收发小组消息
3. **邀请管理**：支持多个邀请，但只能接受一个

### 3. WebSocket消息扩展

#### 新增消息类型：
- `subgroup_message` - 小组消息
- `subgroup_invite` - 小组邀请通知
- `subgroup_member_join` - 成员加入通知
- `subgroup_member_leave` - 成员离开通知

#### 消息路由策略：
```java
// 只向小组成员发送消息，非成员无法收到
if (isSubgroupMember(userId, subgroupId)) {
    sendToUser(userId, message);
}
```

### 4. 前端界面设计

#### 小组管理界面：
- **当前小组Tab**：显示当前参与的小组信息
- **创建小组Tab**：创建新小组并邀请成员
- **邀请处理Tab**：处理收到的小组邀请

#### 聊天模式切换：
- 支持在**群聊模式**和**小组模式**之间切换
- 小组模式下只显示小组消息
- 明确的视觉指示当前处于哪种模式

## 🎨 核心特性实现

### 1. 互斥性约束实现
```java
@Transactional
public Boolean acceptSubgroupInvite(Integer inviteId) {
    // 检查是否已在其他小组
    if (!canJoinSubgroup(userId, parentGroupId)) {
        throw new BusinessException("您已在其他小组中，无法加入新小组");
    }
    
    // 加入小组（数据库约束确保原子性）
    return joinSubgroup(inviteId);
}
```

### 2. 消息隔离机制
```java
// 只有小组成员才能收到小组消息
public void sendSubgroupMessage(SubgroupMessage msg) {
    List<Integer> memberIds = getSubgroupMemberIds(msg.getSubgroupId());
    
    for (Integer memberId : memberIds) {
        sendMessageToUser(memberId, msg);
    }
    // 非成员无法收到消息
}
```

### 3. 前端状态管理
```javascript
// 确保用户同时只能在一个小组中
var subgroupState = {
    currentSubgroup: null,      // 当前唯一的小组
    pendingInvites: [],         // 多个待处理邀请
    isInSubgroupMode: false     // 聊天模式标识
};
```

## 🔒 安全性考虑

1. **权限验证**：确保只有群成员才能创建小组
2. **数据隔离**：小组消息严格隔离，非成员无法访问
3. **并发控制**：使用数据库约束防止并发加入多个小组
4. **输入验证**：前后端双重验证用户输入
